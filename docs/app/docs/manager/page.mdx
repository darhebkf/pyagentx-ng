# Manager

Query SNMP devices with snmpkit's high-performance async manager.

## Quick Example

```python
import asyncio
from snmpkit.manager import Manager

async def main():
    async with Manager("192.168.1.1", community="public") as mgr:
        descr = await mgr.get("1.3.6.1.2.1.1.1.0")
        print(f"Device: {descr}")

        async for oid, value in mgr.bulk_walk("1.3.6.1.2.1.2.2"):
            print(f"{oid} = {value}")

asyncio.run(main())
```

## Configuration

```python
from snmpkit.manager import Manager

mgr = Manager(
    host="192.168.1.1",
    port=161,              # SNMP port
    community="public",    # v1/v2c community string
    version=2,             # 1, 2 (v2c), or 3
    timeout=5.0,           # Request timeout (seconds)
    retries=3,             # Retry count on timeout
)
```

<Callout type="info">
Use `version=2` for SNMPv2c (default). SNMPv3 with USM authentication is coming in v1.2.0.
</Callout>

## Operations

### GET

```python
value = await mgr.get("1.3.6.1.2.1.1.1.0")
```

### GET Many

```python
values = await mgr.get_many(
    "1.3.6.1.2.1.1.1.0",
    "1.3.6.1.2.1.1.3.0",
    "1.3.6.1.2.1.1.5.0",
)
```

### WALK

```python
async for oid, value in mgr.walk("1.3.6.1.2.1.2.2"):
    print(f"{oid} = {value}")
```

### BULK WALK

```python
async for oid, value in mgr.bulk_walk("1.3.6.1.2.1.2.2", bulk_size=25):
    print(f"{oid} = {value}")
```

### SET

```python
from snmpkit.core import Value

await mgr.set("1.3.6.1.2.1.1.5.0", Value.OctetString(b"new-hostname"))
```
